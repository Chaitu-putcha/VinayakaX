# 🛕 VinayakaX – Smart Festival Management Platform

VinayakaX is a smart web-based festival management platform designed to simplify and digitize the management of religious and community festivals.

The platform provides features for managing events, competitions, volunteers, donations, announcements, schedules, sponsors, galleries, live updates, and more.

## 🚀 Features

- 🔐 User Registration & Login
- 👤 User Profile Management
- 📢 Festival Announcements
- 🎉 Event Management
- 🏆 Competitions Management
- 🤝 Volunteer Management
- 💰 Online Donations
- 🏢 Sponsors Management
- 📅 Festival Schedule
- 🖼️ Festival Gallery
- 🔴 Live Festival Updates
- 💬 Live Chat
- 🤖 AI Chatbot
- 🔔 Notifications
- 👨‍💼 Admin Dashboard
- 📱 Responsive UI for Mobile and Desktop
